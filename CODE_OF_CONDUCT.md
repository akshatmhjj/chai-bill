# Code of Conduct

Chai Bill is for people who share a home, and the project should feel like a good flat: considerate,
a bit playful, and no one made to feel small.

## Our pledge

We want everyone to be able to take part, whatever their experience, background, identity or how they
write code. Be kind, assume good intent, and help each other learn.

## What we expect

- **Be respectful.** Disagree about ideas, never about people.
- **Be patient.** Many contributors are new to open source, to Postgres, or to English. Explain, don't scold.
- **Give useful feedback,** and receive it graciously. Reviews are about the work.
- **Stay on topic** in issues and pull requests, and keep discussions constructive.
- **Respect privacy.** Don't share anyone's personal information, and never put real financial data or
  credentials in an issue, a screenshot or a test.

## What we won't accept

Harassment, discrimination, insults, personal attacks, sexualised language or attention, trolling,
doxxing, or spam. Using the project to target someone isn't welcome either.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break this code, and may restrict
participation for anyone who does so repeatedly or seriously.

To report a problem, contact a maintainer privately through GitHub (for example from the owner's profile
page, or by using the repository's private reporting option). Reports are handled discreetly and taken seriously.

This Code of Conduct applies everywhere the project is discussed: issues, pull requests, and any space
where you represent it.
